# Batzli

Persönlichi Spar-App: Tages-, Wuche- und Monetsbudget pro Kategorie, Streak, Level, Abzeiche und Sparziel.
Lauft als Web-App uf em iPhone-Homescreen. Alli Date bliibed lokal uf em Grät (localStorage), kei Login.

- `src/app.html`: de ganz App-Code (HTML, CSS, JS in einere Datei)
- `sh build.sh`: baut `docs/index.html` us `src/app.html`
- `docs/`: d Website, wo GitHub Pages usliferet
